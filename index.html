Open the exam folder

Choose or drop the folder with misc/grafo-copie.json, correzioni/ and risposte/. The viewer finds the graph JSON inside it and can read every exercise file straight away. Edges are drawn with a thickness that follows confidence, and clicking one opens its files side by side. 

{
  "name": "My graph",
  "elements": {
    "nodes": [
      { "data": { "id": "a" }, "style": { "label": "Node A" } }
    ],
    "edges": [
      {
        "data": {
          "source": "a",
          "confidence": 0.6,
          "exercises": ["E1", "E2"]
        }
      }
    ]
  }
}

Choosing the exam folder grants read access once, so exercise files open without another prompt. You can also drop a graph JSON file; the viewer will ask for its exam folder before you open any exercise.
